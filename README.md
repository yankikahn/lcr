# Free GitHub Pages Website

This repository contains a simple static website that can be hosted for free with GitHub Pages.

## Files

- `index.html` - the page content
- `styles.css` - the site styling

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload these files to the repository root.
3. In GitHub, open `Settings` > `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and the `/ (root)` folder.
6. Save, then wait a minute for the site to go live.

Your site URL will usually look like:

`https://your-username.github.io/your-repository-name/`

If you want a custom domain later, GitHub Pages supports that too.
